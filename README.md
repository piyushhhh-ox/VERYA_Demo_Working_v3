# VERYА — Stage 1

A responsive, multi-page frontend prototype for VERYА, built with HTML, CSS and JavaScript.

## Run
1. Extract the ZIP.
2. Open the `VERYA` folder in VS Code.
3. Open `index.html` with Live Server (recommended), or open it directly in a browser.
4. Start with `index.html`.

## Included
- Premium coastal visual system
- Responsive homepage
- Explore page with filters
- Waypoint-style destination map
- Smart Trip Finder
- Local recommendation engine
- Recommendation results + “Why we picked this”
- Destination details
- Demo profile/settings
- My Trips persistence
- localStorage saves
- Subtle desktop custom cursor
- Micro-interactions and scroll reveals

## Note
This is the frontend prototype. Images currently use remote Unsplash image URLs. The demo profile/login behavior is intentionally local-only; a real hosted product should later use a secure backend/authentication system.
