# VERYA – Travel Planner Website

## Project Overview

VERYΑ is a modern travel planning website designed to help users discover and plan trips according to their budget and travel preferences.

The website provides a simple and visually engaging interface where users can explore destinations, find suitable travel options, create trip plans, and manage their planned trips.

## Project Name

**VERYΑ – Smart Travel Planner**

## Objective

The main objective of VERYA is to make travel planning easier by helping users explore destinations and organize trips based on their available budget and preferences.

## Key Features

- 🏝️ Explore different travel destinations
- 💰 Budget-based travel planning
- 🗺️ Destination information and recommendations
- 📋 Trip planning interface
- ❤️ Save and manage planned trips
- 👤 User profile interface
- ⚙️ Settings interface
- 📱 Responsive and user-friendly design
- ✨ Smooth animations and interactive elements
- 🌊 Light and beach-inspired visual theme

## Website Pages

The project contains multiple interfaces/pages:

- **Home** – Introduction and quick access to travel planning
- **Explore** – Browse available destinations
- **Finder** – Find travel options based on preferences and budget
- **Destination** – View detailed destination information
- **Plan Trip** – Create and organize a trip
- **My Trips** – View planned trips
- **Profile** – User profile interface
- **Settings** – Website/user settings
- **Results** – Display travel recommendations
